Finding: F-08 - Weak password hashing and password disclosure
Verification request: Authenticated administrator request to GET /admin
Observed result: Response contained id, username, and role only; no password property was returned.
Expected secure result: Password hashes are generated with Werkzeug's password hashing and never serialized to clients.
Root cause addressed: MD5 was replaced with generate_password_hash/check_password_hash and the admin projection excludes password.
